# 15秒视频规范与固定交付格式

用于角色、场景已确认且对应图片收到后的第三阶段。先保留剧本内容、组织节奏，再填写格式。

## 剧情与节奏

内部列出事件、关键动作、作用对象、结果、道具信息、人物关系、台词及先后因果。改编为画面指令时逐项保留；景别和运镜可以设计，剧情改动需说明并由用户决定。参考图固定视觉外观，不替剧本决定动作是否发生。

| 叙事类型 | 时间与表现重点 |
|---|---|
| 连续文戏 | 对白、潜台词和必要反应，能同框表达时保持同框 |
| 快闪回忆、预告蒙太奇 | 直接进入关键事件，减少预备动作，按剧本切换时间或地点 |
| 动作过程 | 让起因、接触和结果可读，连续动作可由单机位完整拍摄 |
| 揭示、反转、结尾 | 围绕信息出现组织视线与镜头，停顿由剧情需要决定 |

每段固定3–4个编号镜头，总计15秒；每镜1–2机位。跨场景闪回可以在一段中出现，场数取决于事件和台词容量，不按地点分配固定15秒。跨场景切换设在编号镜头边界，每个场景分别锚定图片和初始状态。

不同镜头不必等长。时间是对白、动作、反应共同使用的预算，并行发生时不重复计时。快闪不等于所有画面同样短，信息密集的动作可短，必要台词可跨画面连续。用户原稿如要求比当前3–4镜头、每镜1–2机位更密集的独立画面数量，明确呈现约束冲突，先由用户决定调整哪项，不把多个切镜藏在一条A描述里。

## 单机位与A/B的选择

先给每个编号镜头确定一个表达任务，设计能实现该任务的A机位，再判断B是否必要。

| 实际需求 | 选择 |
|---|---|
| 单人动作与表情在当前画面清楚可见 | A |
| 双人同框足以看清动作和回应 | A |
| 连续动作的力度依赖完整过程 | A，必要时连续跟随或移动 |
| 关键听者反应在A中被遮挡、太小或背对镜头 | A表现触发，B表现具体反应 |
| 关系全景不足以辨认剧情关键细节 | A交代关系，B揭示细节 |
| 动作结果需要另一个角度才读得懂 | A动作，B承接结果 |

增加B前内部回答：B让观众多知道了什么，为什么A不能清楚兼顾？仅换角度、重复动作、例行吞咽抿嘴或为了凑快节奏，不构成新增信息。能在A中读出的情绪就留在A内；需要捕捉情绪变化时，切点落在实际触发上。

A/B共享标题中的镜头时长，比例按内容分配，不强制均分。B承接A已发生的状态，持物、手的位置和动作进程连续；同一个动作不会因切换从头再演。一个机位是一段连续拍摄，可推拉、平移、转焦，但不含“硬切另一个特写”等隐藏剪辑。

机位组合没有固定配额：全单机位、混合或全双机位均可能合理。以当前剧情选择，不复制示例的组合。最终正文只呈现电影指令，选择理由留在内部。

## 空间与视觉

在“人物初始站位与空间关系”中写清各场人物位置、朝向、主要地标、道具与当前外观状态。每个A/B标记携带该场地标、景别和运镜；同场维持动作轴线。地标前缀用于标识拍摄区域，不等于地标必须入镜；指定背景物件时，核对它相对摄影机和人物的实际方向，避免站位与背景要求矛盾。换场明确硬切，不描写人物跨场瞬移。

人物多视图是同一角色的多角度身份参考。普通背景群众依据剧本补入，不为每个群众虚构参考图。关键动作所需物件若没有独立图片，可以按已定稿的文字外观或场景内可见物件表达；缺图不等于删除剧情，确有外观歧义时只确认该项。

手持微呼吸用于需要贴近人物的中近景和对峙，稳定微距用于精密接触和道具，平稳滑轨用于冷静观察。运镜服从可读性。升格等摄影词属于意图，不代表已设置实际输出帧率。

## 台词、情绪与声音

对白逐字保留原文及语言，中文译文放在提示词外供理解。一个完整台词标签只出现一次；声音可从说话人画面连续跨切到听者、道具或动作，明确“同一句台词继续作为画外声音”。无须等说完再安排所有动作和反应。开头就是画外音时，在标签上方写“画外音”。

说话人与口型一致，听者闭口反应；人物没有台词时不强加says。环境声、动作声与人声承担衔接，配乐按用户明确要求处理，默认固定声明为无背景音乐。用户要求配乐与固定声明冲突时明确确认交付选择，不能同时写两套相反要求。

从情绪素材库选适合景别与事件的可见信号，写部位动作与视觉结果。原稿未要求的长时间酝酿、反复小动作不用于填满时长。Speaker编号和基础声线跨段固定，情绪影响语速、呼吸、音量。

按台词长度、语速和停顿核对预算；没有朗读或合成验证时不声称实测可容纳。过载先去掉新增铺垫、调整动作并行与切点，仍过载则说明需拆分或调整内容，不擅自删改台词。

## 模型适配边界

本技能沿用以下对白交付约定，不称其已获官方验证。角色名两侧的半角尖括号是实际输出字符，不是应删去的占位符。用具体名字填写后形如：

```text
<江澜> (S2) says:
<d>[Chinese]你猜。</d>
```

将姓名、Speaker编号、语言和台词替换为当前剧本内容，保留上述其余字符和换行。交付前逐句核对这一字面结构。

用户给出已验证语法时沿用。实际调用生成服务前，按指定模型版本核对时长、参考图数量及语音能力；不能把本技能的3–4镜头、15秒当作所有模型的硬件限制。不支持原生语音的接口须说明配音适配方案。

## 固定五字段模板

镜头标题写实际机位数与约时长；单机位只写A，有必要才写B。下面的4镜头与机位组合仅展示格式，使用时根据剧情选择3或4镜头及每镜机位数；维持标题结构，不替换成时间码列表。“镜头组”是内部理解，不加进正式标题。

```text
【参考图像锚定】

图像1是[角色A]，保留参考图中的面部特征、[发型]、[服装材质款式]、[配饰]、身材比例以及整体外貌。
图像2是[角色B]，保留参考图中的面部特征、[发型]、[服装]、身材比例以及整体外貌。
图像3是[场景]，保留参考图中的空间结构、建筑材质与光影色调。

【分镜】

人物初始站位与空间关系：[各场角色位置、朝向、距离、地标与道具状态]。[连续拍摄或跨场回忆的关系及切场边界]。环境音：[声音]。

镜头1：[主题]（共1机位·约4秒）。
- [机位A·空间地标+景别运镜]：[同一连续机位内能完整表达的事件]。

镜头2：[主题]（共2机位·约4秒）。
- [机位A·空间地标+景别运镜]：[动作或说话人的触发]。
<角色A> (S1) says:
<d>[Chinese][完整台词]</d>
- [机位B·空间地标+景别运镜]：[承接A，呈现必要的新信息；按需要注明同句声音延续]。

镜头3：[主题]（共1机位·约3秒）。
- [机位A·空间地标+景别运镜]：[动作及可同框看见的反应]。

镜头4：[主题]（共1机位·约4秒）。
- [机位A·空间地标+景别运镜]：[原剧情结果与下段承接点]。

【Speaker 声线设定】

S1（角色A）：[年龄感、性别、音域音色、基础咬字语速、当段情绪变化及表演边界]。

【禁止项】

文字/UI/水印/Logo/角标/可读文字/真实UI

【强制声明】

无背景音乐,仅保留环境音与人声和音效;画面禁字幕/文字/水印/Logo;禁止可读文字(指画面字幕文字,不含人声台词)
```

图像行按实际上传数量扩展，多个场景分别建档。纯环境音段Speaker写“本段无人声”；有非对白人声时保留对应声线。五字段之外的制作说明写在代码块外。
