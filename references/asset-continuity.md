# 资产身份、图片映射与连续性

## 最小记录

本文件供助手内部维护映射与连续性。按项目规模用简短记录即可，默认不向用户输出资产表，不增加单独确认步骤。

| 类型 | 稳定ID示例 | 必需信息 |
|---|---|---|
| 角色 | C01 | 姓名/稳定标识，年龄、外貌、发型，服装版本，固定配饰，信息来源 |
| 造型 | C01-V01 | 上装、内搭、下装、必要鞋履及材质颜色，使用段落 |
| 场景 | E01 | 地点、布局、门窗/主物件位置、光源方向、时间版本 |
| 道具 | P01 | 外观、材质、尺寸关系、固有磨损、基础状态 |
| 声音 | S1 | 对应角色、年龄感、音域、音色、咬字、基础语速、表演边界 |

每个图片资产另记图片路径或用户附件标识，以及状态：文字设定 / 待出图 / 已出图未检视 / 已检视。没有真实图片时用“待上传”，不用虚构路径。

角色造型来源可记“用户原文”“用户参考图”“用户授权补充”。同角色换装建立新的V版本，身份与声线保持不变。场景昼夜版本沿用空间布局，分别记录灯光。

## 三层状态

1. **基础资产**：角色原始造型、物品固有磨损、建筑原有陈旧痕迹。
2. **片段初始状态**：进入该段时已发生的改变，例如前段留下的泪痕、桌上摆好的证物。
3. **镜头内变化**：本镜发生的抬手、开门、递物、液体泼洒、服装变湿。

片段初始状态不是必须干净。基础资产干净与剧情连续性可以同时成立。

如需生成“衣领沾酒版”参考图，创建C01-V01-STATE01，标明由哪段事件造成、适用哪些后续片段；其他身份与衣装维持基础版本。状态图不是默认必需的额外生图任务。

## 映射与站位

稳定身份与段内图像编号分开：

| 片段 | 实际上传顺序 | 身份与声线 |
|---|---|---|
| 01 | 图像1=C01，图像2=C02，图像3=P01，图像4=E01 | C01=S1，C02=S2 |
| 02 | 图像1=C02，图像2=E02 | C02仍为S2 |

已给定上传顺序时以实际顺序为准。单人资产图通常居中，人物在故事场景里的左右位置写在“人物初始站位与空间关系”中。多人参考图通过图内位置与服装识别具体角色，不把参考图左侧误当成永久剧情站位。

推荐一张图对应一个关键资产；若实际为多人合照，逐一说明同一图像内的角色位置，不虚构独立图片。用户图片数量限制优先；未获知平台上限时不编造上限，可列出最小必要参考图集合。

独立道具图有助于以下情况：辨认外观关系到剧情、反复特写、跨人交接或跨段追踪。普通陈设归场景。纯画外音角色可以只有声音档案，无需为了声音虚构出镜参考图。

## 连续性记录

每段结束内部记录，供下一段承接，默认不附在用户交付中：

```text
片段01结束：
人物：C01桌左侧站立，右手已松开；C02桌右侧坐姿，目光落在P01。
外观：两人造型沿用各自V01，无新增污渍。
道具：P01正面朝上停在桌面右半部，归属未变，已从C01手中释放。
场景：E01夜，后墙门关闭，右侧台灯持续亮着。
承接：C02左手靠近P01但尚未触碰。
```

若片段02连续发生，开场沿用该状态；回忆、时间跳跃或交叉剪辑则按各自时间点建立状态。若用原始空场景图作参考，分镜明确桌面当前道具状态；模型难以稳定承接时，可建议用前段末帧作状态参考，但不要声称仅靠文字就能保证连续性。
