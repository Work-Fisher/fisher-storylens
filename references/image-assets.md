# 角色、场景、道具生图提示词

## 共同规范

全部以中文描述，胶片型号、焦段等必要标识可保留。每条提示词独立代码块；角色名、场景名或道具名放块外，资产ID与版本由助手内部维护，不要求在图内生成标签。

采用具体物件、位置、材质、新旧和光线方向。基础资产呈现原始外观；事件状态放到分镜或单独派生版本。单张单主体，不默认四宫格、不添加画幅或黑边指令，不另设负面提示词块。

角色和场景依照用户模板保留局部短语“无油光、不泛油”等；“不写负面提示词”指不另加负面词清单，不删除这些指定画质短语。

所有生图提示词末尾使用固定尾句：

```text
光影层次感，电影质感，艺术氛围，高级的氛围感，梦幻，
```

固定尾句仅用于生图，不传递为视频必须梦幻化的要求。为满足下游纯净画面，优先设计素面包装、无字饰品、抽象装饰画等；屏幕、证件、键盘和瓶标不依赖可读内容传递剧情。确需阅读的信息通过台词或后期制作表达。

## 角色资产

顺序：画质光线 → 国籍、年龄、面孔 → 身份气质 → 身高体型 → 哑光皮肤 → 发型 → 五官眼睛 → 克制表情 → 上装、内搭、下装 → 固定配饰 → 站姿取景 → 镜头背景 → 正常比例 → 固定尾句。

本技能默认东亚人物，写明确国籍及“亚洲面孔，东亚五官”。用户明确设定其他人物外貌时忠实采用，不把韩剧风格强行等同于韩国国籍或东亚外貌。成年、中年、老年称谓与年龄匹配。

默认“双眼都睁开，对称双眼”，表情以便于身份辨认为准。明确的人物身体特征或用户定稿优先。哑光指皮肤，不能据此把金属、丝绸、眼睛等也写成无反光。

只写造型固有配饰；临时酒杯、U盘、武器独立建道具。领口松垮、歪领带可以是原始风格；“刚被扯开的领口”是事件状态。默认站立、全身清楚，关键鞋履应写，非关键细节可省略。

人物基准图统一浅灰棚拍与均匀漫射光；把密室暖光、雨夜霓虹等故事环境光交给场景和视频，避免同一资产里出现互斥照明。

### 模板

```text
最高画质，杰作，超精细，干净棚拍光线，一位【国籍及年龄相符的人物称谓】，亚洲面孔，东亚五官，【年龄】岁，【身份与气质】，身高【厘米】，身形【体型】，哑光皮肤质感，【肤色】，皮肤通透，无油光，不泛油，【妆容或自然面容】，【发色、长度、造型】，【眉形】，【眼型】，【瞳色】眼睛，双眼都睁开，对称双眼，眼神【克制的常态气质】，【鼻梁】，【唇形】，穿【上装颜色、面料、款式、领型、纹理】，内搭【】，下身【颜色与版型】，【必要鞋履与固定配饰】，标准站立姿势，双手自然垂放，全身可见，从头到脚都在画面内，正常透视，50mm标准镜头，干净浅灰色棚拍背景，柔和均匀漫射光，正常身材比例，光影层次感，电影质感，艺术氛围，高级的氛围感，梦幻，
```

不存在的内搭、妆容、配饰字段直接省略。前面已写体型，末尾只写正常比例，不重复“纤细”等标签。用户只需肖像时，将全身和站姿改成头肩肖像；不要在同条提示词同时要求脸部特写和从头到脚可见。必要时为全身图另配同身份肖像，而非默认增加所有资产数量。

## 无人场景资产

两段式：第一段空间白描，第二段摄影参数。场景默认仅含空间和物件，通过内容本身实现无人。

白描顺序：地点与时间 → 空间结构 → 关键地标与物件相对位置 → 材质、新旧和固有磨损 → 光源方向、颜色、照明范围、阴影 → 可见空气质感。

原模板的声音、温度、气味可用于构思，最终生图优先写可见证据，声音交给视频。场景基本版本不混入本段动作造成的反锁、碎玻璃、撞翻家具；原本废弃破败的空间可以保留其固有损坏。

空间主参考图优先展示门、窗、桌、灯等布局，采用适合交代环境的景别及景深。情绪氛围图可另用浅景深，但不能让唯一空间锚点全部虚化。

### 模板

```text
【地点、时间、整体空间结构】，【关键地标与明确位置】，【主要物件的材质、新旧与相对布局】，【光源位置、光色、照射范围与阴影方向】，【可见空气质感】，
【摄影风格】，【胶片型号】胶片质感，【具体色调与颗粒】，【焦段】mm镜头，f/【光圈】，【景深与空间可辨认程度】，光影层次感，电影质感，艺术氛围，高级的氛围感，梦幻，
```

按场景与时间选择风格，不按段号轮换。相同空间和连续时间沿用配色、主光方向及胶片质感；换场时仍考虑全片共同风格。不添加“求救无门”一类不可拍的导演收尾句。

## 关键道具

一段式：物品与产品展示 → 材质、尺寸、重量感 → 固有磨损 → 展示角度 → 纯色背景及打光 → 胶片质感和镜头 → 固定尾句。

默认45度单品展示，可按物品结构改成稳定摆放。悬浮是资产展示手段，视频里按重力与支撑关系使用道具。事件血迹、摔裂等另建状态版。

```text
【道具名称】，产品展示图，【材质、形状、尺寸和重量感】，【结构与固有磨损】，【素面或抽象表面设计】，45度角单品展示，【纯色背景】，【光源方向和材质反光】，【胶片质感】，【焦段与光圈】，【合适景深】，光影层次感，电影质感，艺术氛围，高级的氛围感，梦幻，
```

## 出图词检查

角色身份与年龄明确，默认东亚面孔、哑光、双眼睁开；人物只含原始造型，无临时持物。场景为空间与物件，布局可辨。无四宫格、额外负面词块、画幅黑边要求。每条固定尾句完整，连续场景风格一致，关键道具表面不提前带入可读文字。
