# 跨场景快闪示例

独立虚构示范，展示格式与机位选择，不代表用户项目内容，不复制其动作进入其他剧本。假设已收到并检视本例所述图片。

## 原始输入

15秒闪回。第一场在办公室，主管把解雇信推到林岚面前，说“明天不用来了。”林岚把员工卡放下。第二场在家，父亲把催款信摊在餐桌上，说“房租，明天就到期。”林岚打开钱包，里面只剩一枚硬币；父亲看清后，把催款信翻扣。两场属于不同时间的记忆，所有角色成年。

## 示例交付

```text
【参考图像锚定】

图像1是林岚，保留黑色齐肩发、浅蓝衬衫和深灰长裤及面部特征。
图像2是主管，保留灰色西装、白衬衫和面部特征。
图像3是父亲，保留灰白短发、褐色开衫和面部特征。
图像4是办公室，保留中央办公桌、右侧窗与左侧出口位置。
图像5是家中餐厅，保留木餐桌、后方厨房门和顶部暖灯位置。

【分镜】

人物初始站位与空间关系：镜头1–2为办公室回忆，林岚在桌左，主管在桌右，解雇信位于主管手边。镜头3–4硬切家中餐厅回忆，林岚坐桌左，父亲坐桌右，催款信在父亲手中，钱包在林岚口袋。两场各自保持桌面轴线，信纸使用模糊排版，由台词与动作交代含义。办公室空调低鸣切换为家中冰箱轻响。

镜头1：被辞退（共1机位·约4秒）。
- [机位A·办公室办公桌区双人侧面中景·稳定机位]：画面切入主管已经将解雇信推向林岚的动作，纸张滑到林岚手前。主管抬眼说话，林岚看着停住的信，两人面部与信同时清楚可见。
<主管> (S2) says:
<d>[Chinese]明天不用来了。</d>

镜头2：交回员工卡（共1机位·约2秒）。
- [机位A·办公室办公桌区手部特写·稳定近摄]：林岚把员工卡放在解雇信旁，松手抽回。卡片正面是不可辨识的色块，卡角碰桌发出轻响，硬切下一场。

镜头3：房租期限（共2机位·约5秒）。
- [机位A·家中餐桌区父亲中近景·手持微呼吸]：父亲将催款信摊在桌面，指尖停在纸边，抬头对林岚说话。
<父亲> (S3) says:
<d>[Chinese]房租，明天就到期。</d>
- [机位B·家中餐桌区林岚手部特写·稳定近摄]：同句尾音延续，林岚从口袋取出钱包，打开零钱夹层。镜头清楚呈现夹层里仅剩的一枚硬币。翻开钱包的动作一次完成。

镜头4：把信翻过去（共1机位·约4秒）。
- [机位A·家中餐桌区双人中近景·手持微呼吸]：林岚将打开的钱包停在桌边，父亲低头看清硬币，指尖捏住催款信一角，将信翻扣。林岚看着父亲收回手，两人没有说话，画面停在翻扣的信与打开的钱包之间。

【Speaker 声线设定】

S2（主管）：成年男性，中音，干净偏冷，正常语速，短句平直，不拖长句尾。
S3（父亲）：中老年男性，中低音，轻微沙哑，语速平稳，尾句气息较轻，不刻意煽情。

【禁止项】

文字/UI/水印/Logo/角标/可读文字/真实UI

【强制声明】

无背景音乐,仅保留环境音与人声和音效;画面禁字幕/文字/水印/Logo;禁止可读文字(指画面字幕文字,不含人声台词)
```

## 内部选择依据

总计4个镜头、15秒。办公室到家在编号镜头边界切换。镜头3的B提供A看不清的硬币数量，是后续父亲翻信的因果；其他镜头在单一构图内即可表达。两个场景分别初始化状态，声音可跨同场A/B。解雇信、员工卡、催款信、硬币和翻扣动作全部保留；没有用抽象悲伤替代这些事件。
